## 验证范围

目标入口：`http://127.0.0.1:8000/workspace`

应覆盖以下交互：

- 上传一张可读普通图片并提交普通求解：不因 CircuitIR 缺失而拒绝；
- 上传题目图 + 答案图并在提示中说明顺序：结果显示混合角色语义；
- 上传表格或波形图：进入通用视觉/对应能力提示，不追加电路渲染节点；
- 明确要求生成电路图：仅在有可信 CircuitIR 且开关为 controlled 时显示可视化分支；
- `off` 模式：不创建可视化工具节点；
- 失败或不可读图片：保留受控错误/待复核信息，不伪造成功。
