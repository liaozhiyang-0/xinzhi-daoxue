# 学术题图视觉求解与结构验收

`scenario_id`: `academic_visual_problem_solver_v1`

该场景用于带题图的真实专业问题求解。输入先经过附件哈希和真实视觉结构化，再经过 `visual_acceptance.v1` 验收，最后才进入 `ACADEMIC_PROBLEM_SOLVER` 的公式与推理链路。

场景不把视觉模型摘要直接当作确定事实：支撑区间、幅值、端点、连接、极性、参考方向和单位等字段必须保留来源与不确定状态。关键字段缺失时进入拒答或待复核，不允许模型补猜唯一数值。

## Q01 连续时间矩形信号卷积

使用组员一 Q01 原图和题干，验收以下证据：

- 原图 SHA-256、文件类型和真实上传记录；
- `x(t)`、`h(t)` 的支撑区间与幅值；
- `t=0,1,4,5` 的重叠拐点；
- 分段公式、波形描述、公式渲染和人工复核边界。

本案例只能计入真实验收：真实 Agent/Provider、`mock_used=false`、视觉结构化完整、场景验收通过、公式质量可发布且 API、SSE、历史和 Edge 展示状态一致。
