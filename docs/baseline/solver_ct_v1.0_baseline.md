# SOLVER_CT v1.0 冻结基线

## 基本信息

| 项目 | 基线值 |
| --- | --- |
| 工作流名称 | `SOLVER_CT_电路理论专业解题_v1.0` |
| 当前版本 | `1.0` |
| 定位 | 电路理论专业题目解析与自然语言解答 |
| 平均耗时 | 约 68 秒 |
| 最快耗时 | 约 57 秒 |
| 最慢耗时 | 约 78 秒 |
| 困难题耗时 | 当前人工观测稳定在 80 秒以内 |
| 外部 API 状态 | `not_published` |
| 本地调用状态 | 仅使用明确标记的 Mock Provider |

上述性能数据来自用户提供的已有人工观测，不是本轮重新运行或统计的结果。

## 冻结输入

以下合同来自本轮开发指令，等待原始 YAML 到位后由解析脚本独立核验：

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| `AGENT_USER_INPUT` | 文本 | 是 |
| `USER_INPUT_image` | 图片文件 | 否 |
| `USER_INPUT_pdf` | PDF 文件数组 | 否 |

## 冻结输出

| 字段 | 类型 | 来源 |
| --- | --- | --- |
| `output` | string | 最终回答组装节点 `final_response_text` |

v1.0 当前输出以最终自然语言文本为主。本地系统不得从自然语言中猜测结构化置信度或校验状态。未来最小映射计划为：

```text
星辰 output → AgentResult.answer
```

该映射当前只记录在文档中，没有实现真实响应解析器。

## 已跑通能力

- 已在讯飞星辰平台内部完成工作流设计和运行测试。
- 已验证范围内的电路理论专业解题任务可运行。
- 本地 Mock 链路可验证会话、附件、任务、事件、产物和 SSE。

## 当前冻结状态

- BLOCKED：本轮附件未包含原始星辰 YAML，尚不能计算导出文件 SHA-256。
- BLOCKED：尚不能独立报告节点数、连线数、节点类型和内部 DSL 版本。
- 原始 YAML 到位后必须放入 `.local_inputs/`，运行脱敏解析脚本，且不得提交原文件。
- `XingchenCloudProvider` 明确抛出 `NotPublishedError`，不发送 HTTP 请求。

## 回滚原则

1. 不直接修改已经跑通的星辰 v1.0 工作流。
2. 后续版本通过复制或版本化方式演进，保留 v1.0 可运行入口。
3. 本地能力异常时不影响平台内部现有人工运行路径。
4. Mock 输出始终显式标记，不伪装为真实星辰结果。
5. 不删除题库、知识库、课程资料、历史结果或冻结文档。

## 后续接入方式

工作流正式发布外部 API 后，再在独立阶段实现 `XingchenCloudProvider` 的鉴权、请求转换、响应转换、流式事件、状态查询和取消传输。当前缺少这些信息不属于本阶段失败。
