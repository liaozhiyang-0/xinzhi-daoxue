## 回滚原则

1. 不直接修改已跑通的星辰 v1.0 工作流。
2. 新版本通过复制或版本化方式演进，保留 v1.0 可运行入口。
3. 本地接入失败时回退到星辰平台现有人工调用路径。
4. 本地 Provider 未配置或不可用时回退到明确标识的 Mock Provider，不伪装成真实结果。
5. 回滚不得删除题库、知识库、历史结果或基线文档。

## 本地系统接入方式

本地 FastAPI 通过 `AgentProvider` 抽象调用工作流。业务层只处理统一的 `AgentRequest` 和 `AgentResult`；`XingchenCloudProvider` 负责正式 API 的请求转换、响应转换、异常映射和密钥保护。真实字段未确认前 Provider 抛出 `NotConfiguredError`，系统默认使用 Mock Provider保证本地链路可运行。
