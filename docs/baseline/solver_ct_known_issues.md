# SOLVER_CT v1.0 已知问题

## 已确认

- 单次运行平均耗时约 68 秒，最快约 57 秒，最慢约 78 秒。
- 困难题当前观测可稳定在 80 秒以内，但尚缺自动化重复试验和统计置信区间。
- 星辰正式 API 字段、鉴权方式和流式事件格式尚未提供。
- 工作流节点、提示词和模型参数尚未完整导出。

## 待验证

- 图片题支持范围与图片质量下限。
- 多小问覆盖率。
- 单位、参考方向和符号约定的一致性。
- Provider 超时后云端运行是否继续。
- 取消和状态查询能力。
- 敏感信息在星辰日志侧的处理方式。

所有未知项均为待确认事项，不代表现有工作流存在对应缺陷。
