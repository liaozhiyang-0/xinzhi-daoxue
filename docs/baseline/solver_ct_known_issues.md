## 已确认

- 工作流已在星辰平台内部完成设计与运行测试。

- 工作流尚未发布外部 API。
- 本地系统本阶段不调用真实星辰网络接口。

- 完整总体架构原文未随本轮附件提供，仓库保留现有架构基线。

## DEFERRED：等待工作流发布 API

- API Base URL 与鉴权协议。
- 工作流外部运行 ID。
- 请求与响应字段。
- 流式事件格式。
- 状态查询和取消接口。
- 星辰文件上传接口。

以上是阶段边界，不代表现有平台内部工作流存在缺陷。

## 本地阶段风险

- 进程内 TaskRunner 在 API 进程重启时会中断运行任务，后续应迁移到独立 Worker。
- SQLite 适合测试，不代表 PostgreSQL 的全部并发行为。
- Mock benchmark 只验证工程链路，不提供真实解题正确率。
