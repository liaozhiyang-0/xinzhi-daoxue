# CapabilityPack 设计

CapabilityPack 表示跨课程复用的专业能力。它声明 ID、显示名与所需工具，校验输入并摘要结果，但不承担完整 Agent 流程。

当前注册代数、微积分、复数、方程组、微分方程、信号变换、布尔代数、逻辑/状态机、电路分析、代码/HDL、单位和绘图能力。

唯一 Tool Registry 同时保存工具 ID、支持能力、输入/输出 schema、超时、副作用、沙箱要求、启用状态和确定性标记。calculator、SymPy 方程、线性方程、复数和单位工具已启用；绘图、Python 执行、布尔/真值表、信号变换、HDL 静态分析已注册，但在有安全实现前保持 disabled。

确定性工具失败只记录错误类型与警告，不把异常原文、密钥或大对象写入 GraphState。
