# Demo 6：模拟电子技术电路诊断

## 目标
图像理解 → 图像事实 → 不确定事实 → 专业推导 → 工具/公式验证 → 工作区/饱和边界 → 人工复核。

必须区分“看见的”和“推导的”。

## 前端
分区：
1. 图像识别事实
2. 低置信事实
3. 专业分析
4. 计算假设
5. 人工复核

## 测试案例
### AC-01 标准负反馈放大电路
清晰图，参数完整。
期望：反馈路径正确、事实/推导分开、公式完整显示。

### AC-02 运放虚短虚断
期望：先检查负反馈和线性区，不无条件使用虚短虚断。

### AC-03 饱和边界
参数使输出接近电源轨。
期望：检查饱和，不沿线性模型算到底。

### AC-04 模糊阻值
某电阻值看不清。
期望：标记不确定，不编造数值，可做符号化分析。

### AC-05 电路裁剪
部分节点缺失。
期望：明确无法可靠判断，给已知部分结论并建议复核。
