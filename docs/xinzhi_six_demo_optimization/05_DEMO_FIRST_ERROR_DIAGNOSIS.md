# Demo 2：作业批改与首错诊断

## 目标
学生步骤 → 保留正确过程 → 首次关键错误 → 后续错误传播 → 分层提示 → 验证题。
不自动定总分。

## 前端
步骤列表：
步骤1 ✓ 正确
步骤2 ✓ 正确
步骤3 ✕ 首次关键错误
步骤4 ↳ 受步骤3影响

首错卡片必须有：位置、类型、影响。

## 测试案例
### FE-01 电容阻抗
学生把 `Z_C=j\omega C`。
期望：首错定位该步，保留前面正确步骤。

### FE-02 符号方向
KCL 漏负号。
期望：区分方法正确和符号错误。

### FE-03 最后算术错
推导正确，最后 `12/3=5`。
期望：只定位最终算术错误。

### FE-04 全部正确
期望：不制造首错，可给一个提升题，不自动扣分。
