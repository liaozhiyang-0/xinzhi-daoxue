# TeachingState、Memory 与 mastery 边界

`TeachingStateV1` 是会话工作状态中的短期教学上下文，只描述当前模式、来源任务、
是否有学生作答、当前技能/题型、提示级别和答案披露状态。它随正常会话状态更新，
不新增数据库表或 migration。

三类状态必须分开：

| 状态 | 用途 | 第一阶段是否自动写入 |
|---|---|---:|
| TeachingState | 当前任务/会话的短期教学控制 | 是 |
| Memory | 用户显式启用的长期偏好或事实 | 否 |
| mastery | 经明确学习动作确认的掌握度统计 | 否 |

`student_attempt` 可保存在任务 options 和当前用户消息的 `content_data` 中，以支持
重放、检查和上下文恢复；第一阶段不会因此自动创建错题、长期记忆或掌握度变化。
仅 `check_my_work` 复用已有确定性答案检查，其结果也只是当前任务反馈。

未来若要将结果写入 Memory、错题本或 mastery，必须通过独立、显式、可审计的用户
动作，并补充隐私、撤销、幂等和评测设计。
