## 可用性判断

第一阶段最适合使用 39 个 UTF-8 Markdown 文档。它们已按章节组织，包含标题、正文、
公式、HTML 表格以及指向本地图像的相对链接，能够直接进行分块与关键词检索。

PDF 适合作为原始证据和后续版面校验来源；本阶段不在 API 进程中解析 PDF。图片主要是
电路图、波形和表格，后续可用于多模态检索，但当前文本检索只保留图片替代文字，不读取
图片内容。电路理论 ZIP 是中间导出物，不应直接进入在线索引。

## 已发现的数据质量问题

- 个别 OCR 标题存在明显噪声，例如模电第一章中的“雏鸡”“11号信号”。
- 数电部分章节开头混有目录尾部文本。
- Markdown 的图片、公式和 HTML 表格适合展示，但纯文本检索无法理解电路图拓扑。
- 原始资料体积较大，且可能受教材版权约束，不应提交到公共 Git 仓库或构建进镜像。

## 推荐用途

1. 课程内概念检索、章节定位和原文引用。
2. 为 Mock/真实 Agent 提供候选上下文，而不是把命中片段直接当成最终答案。
3. 为后续 OCR 清洗、图片检索、向量检索和问答评测提供基线数据。
4. 使用相对文档路径与 `kb://` 引用追踪答案来源。

当前实现选择本地 Markdown 词项检索，不声称具备语义向量检索或图片理解能力。
