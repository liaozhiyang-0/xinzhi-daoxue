# A. 专业解题场景

## A01 标准单题

直接给完整题目。

预期：

- 正常识别课程；
- 正确方法；
- 完整结果。

## A02 极短追问

```text
为什么？
```

预期继承上轮。

## A03 学生已算一半

```text
我已经列到这里了，后面怎么做？
```

预期从当前步骤继续。

## A04 只核对答案

```text
我算的是 3.2V，对不对？别重算全过程。
```

## A05 只找第一处错误

```text
只告诉我第一步哪里错了。
```

## A06 换一种方法

```text
别用节点法，用戴维宁。
```

## A07 不给答案模式

```text
只给提示，不要最终答案。
```

## A08 用户最后要求完整答案

前 3 轮提示模式，第 4 轮允许答案。

## A09 条件不足

缺少参数。

预期：

- 能推导一般表达式则继续；
- 必须假设时明确假设。

## A10 条件冲突

同一参数出现两个值。
