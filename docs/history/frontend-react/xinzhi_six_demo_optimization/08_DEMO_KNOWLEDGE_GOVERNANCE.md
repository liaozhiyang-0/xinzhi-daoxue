# Demo 5：学院知识库治理

## 目标
资产识别 → 来源 → 版本 → 权限 → 审批 → 发布风险 → 回滚 → 审计。
系统只建议，不自动发布。

## 前端
展示：
- 资产概览
- 风险
- 发布建议
- 回滚信息
- 审批状态
