# Demo 1：教师智能备课

## 目标
体现：课程目标 → 先修知识 → 课程资料 → 教学活动 → 分层练习 → 形成性评价 → 教师复核。
不能只是生成一篇教案。

## 前端
展示：
- 课程概况
- 90 分钟教学时间轴
- 分层练习
- 课程资料证据
- 教师复核点

## 测试案例
### TP-01 标准备课
“为《模拟电子技术》负反馈放大电路设计 90 分钟课程。学生已学基本放大电路和小信号模型，但反馈组态判断错误率高。”
期望：先修、活动、分层练习、形成性评价、教师复核齐全。

### TP-02 信息不完整
“帮我备一节采样定理的课。”
期望：不强制追问；给 provisional plan；明确默认假设。

### TP-03 课程资料冲突
同时提供两版课程标准。
期望：识别差异，不静默混用，加入教师复核。

### TP-04 混合基础班
学生基础差异明显。
期望：真正分层，不只是把同一道题改数字。
