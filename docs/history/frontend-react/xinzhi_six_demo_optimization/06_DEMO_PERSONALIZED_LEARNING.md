# Demo 3：学生个性化学习路径

## 目标
体现历史学习证据，而不是普通学习计划。

## 前端
展示：
- 当前学习证据
- 薄弱点及证据数
- 学习阶段卡片
- 复测节点
- 教师介入点

不得直接宣称“已掌握”。

## 测试案例
### LP-01
卷积3/5、傅里叶级数4/5、傅里叶变换2/5、采样定理1/4、拉普拉斯4/4。
期望：优先频域与采样；拉普拉斯标记“暂时稳定”。

### LP-02 样本太少
某知识点仅1道正确。
期望：标记证据不足，安排复测。

### LP-03 近期退步
历史很好，最近连续错误。
期望：近期证据权重合理提高。

### LP-04 前置依赖
想学 FFT，但 DFT 薄弱。
期望：先补 DFT。
