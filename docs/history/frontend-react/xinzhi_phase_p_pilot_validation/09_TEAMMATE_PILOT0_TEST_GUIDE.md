# 组员 Pilot 0 真实测试指南

## 每位测试者至少
1. 自己想 2–3 个真实专业问题；
2. 测 1 个六案例；
3. 测 1 个图片/附件；
4. 做 1 次追问；
5. 故意输入 1 次信息不足问题；
6. 尝试 1 次 retry/cancel/resume（如可用）。

## 不要告诉测试者
- Planner 应该选什么
- Skill 应该是什么
- 正确 route
- 内部 Agent ID

## 每任务反馈模板
```text
任务编号：
你想完成什么：
结果是否解决问题：1–5
答案是否正确：1–5
表达是否清晰：1–5
是否可信：1–5
操作是否顺畅：1–5

遇到的问题：
最满意的部分：
最困惑的部分：
是否愿意继续使用：
```

失败时保留截图 + task_id。

不要为了让测试“通过”反复重试直到得到满意答案。
