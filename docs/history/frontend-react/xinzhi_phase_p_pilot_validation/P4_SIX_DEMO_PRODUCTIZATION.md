# P4：六案例产品化收口

## 每个案例固定准备
- 1 个黄金案例
- 2 个备用案例
- 1 个边界案例
- 1 个失败/降级案例

## 黄金案例要求
- 真实 Agent
- 真实 Task 链
- 可重复
- 不依赖手工改数据库
- 不依赖隐藏 Debug
- 结果适合 1–2 分钟讲解

## 六案例
1. 教师智能备课
2. 作业首错诊断
3. 个性化学习路径
4. 科研证据简报
5. 知识库治理
6. 模拟电子电路诊断

## AC
至少准备：清晰运放图、模糊参数图、饱和边界图。

## RB
提前验证外部来源可用性与 fallback。

## 输出
`docs/demo/final_demo_runbook.md`
