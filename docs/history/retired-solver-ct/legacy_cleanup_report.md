# 旧文件与功能清理记录

## 删除

- 被忽略的 pytest 临时目录、Ruff/Mypy/Pytest 缓存和覆盖率文件；
- 根目录临时 SQLite 测试数据库；
- 四个未发布 Agent 的活动注册项、Mock Profile、契约用例和环境变量模板。

## 隔离

- 阶段 0—2.2 架构快照和评审报告；
- 包含未发布 Agent 的旧工作流扩展计划；
- 无仓库内引用的旧 `TaskService` 兼容门面。当前调用方直接使用 `TaskQueryService`。

隔离目标统一位于 `archive_legacy/`。历史材料和旧代码仍可追溯，但不参与运行、导入、测试发现与打包。

## 保留

- 受控启用的现有星辰工作流；
- 本地快速路由、本地知识检索、通用问答与多学科求解能力；
- `/api/v1/tasks`、SSE、上传、数据库和前端页面；
- `SOLVER_CT_V1` 冻结配置和已验证星辰文字/单图片调用；
- 原始课程资料、索引迁移工具、数据库 migration 和跨平台启动器。

## 活动注册表边界

活动注册表当前包含 11 个顶层条目。答题检查意图直接复用 `SOLVER_CT_V1`，不再经过从未发布的 `CHECK_01_ANSWER_REVIEW_V1`；无法匹配既有课程工作流的普通问题由 `GENERAL_QUESTION_V1` 接管，不触发星辰工作流。

## 隔离判据

只有同时满足以下条件的逻辑才进入隔离区：

1. 活动源码、配置、脚本和测试中无引用；
2. 不属于公开 API、迁移、扩展点或冻结基线；
3. 已有明确替代实现；
4. 隔离后通过回归测试验证运行链未受影响。

`task_service.py` 满足上述条件：它只把 `TaskQueryService` 重命名为 `TaskService`，仓库内除自身外无任何引用，且实际查询入口已经直接依赖 `TaskQueryService`。其余看似轻量的 `__init__.py`、Provider 兼容导出、空 integrations 扩展点和 Worker 边界文档均有包结构或扩展契约用途，不作为无用逻辑处理。
