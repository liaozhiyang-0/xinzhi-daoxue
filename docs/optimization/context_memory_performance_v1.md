## 1. 优化依据

基线来自真实模型批次：

`真实测试题/统一格式/evaluation_reports/targeted_retest_20260728T153354Z/raw/isolated/local_optimized_20260729_121311`

该批次 100 例全部完成：

- 通过：72
- 评分失败：4
- 超时：24
- 执行错误：0

与上一轮 53 通过、9 评分失败、38 超时相比，通过数增加 19，超时减少
14，5 个评分误判已消除。剩余 4 个评分失败仍是需要保留的真实诊断错误。

本批次的阶段耗时统计：

- 上下文构建：平均约 9.6 ms，P95 约 27.1 ms。
- 课程检索：平均约 24.3 s，P95 约 59.5 s。
- 模型阶段：P95 约 201.2 s。

因此上下文数据库查询不是总耗时主因，但上下文重复、无效检索和非端到端
时间预算仍会挤占模型生成与最终持久化时间。

## 2. 耗时优化

### 2.1 边界题在检索前拦截

`ACADEMIC_PROBLEM_SOLVER` 在进入本地知识检索前执行与正式求解器相同的
确定性边界判断。对缺图、缺上题条件、非法概率分布、矛盾功率要求等已经无法
继续的输入：

- 跳过课程检索；
- 不调用模型；
- 仍由正式边界策略生成同一类安全回答；
- 在结果中记录 `retrieval_preflight`，不伪造检索证据。

该优化针对上一轮边界题中约 25 秒的无效检索开销。

### 2.2 求解器使用端到端预算

复杂题的 235 秒内部硬截止不再从“进入求解器”重新计时，而是扣除任务前置
上下文、路由和课程检索已经消耗的时间。

例如课程检索已经消耗 40 秒时，复杂求解器实际剩余硬预算约为 195 秒。
接近截止时停止新增可选复核调用，优先完成已有答案的验证、格式化与持久化，
避免“检索 40 秒 + 求解 235 秒”突破 240 秒外层上限。

### 2.3 上下文查询与内容瘦身

- 关闭长期记忆的会话不再查询记忆版本。
- 消息数不足近期窗口时，不再查询不存在的更早历史。
- 当前用户消息不再作为“历史消息”重复注入。
- 当前问题已经存在于规范输入时，不再通过工作状态重复写入提示摘要。
- 记忆按课程范围、稳定偏好、重要度和当前问题相关性排序。
- 上下文配置版本升级为 `conversation-v2`，避免复用旧缓存。

## 3. 记忆功能

- 手动添加、编辑、删除和明确的“记住/忘记”指令保持不变。
- `auto_memory_enabled` 现在真正生效，但默认仍关闭。
- 只有用户主动开启自动记忆，并明确表达长期回答偏好时才自动保存，例如
  “我希望讲解时先给思路再给答案”。
- 普通题目、一次性参数、学生答案和敏感信息不会作为自动长期记忆保存。
- 重复内容复用现有记忆；同类冲突偏好继续使用版本替代机制。

## 4. 前端关联

学生工作台任务详情新增“上下文”页签，展示：

- 本次使用的近期消息和相关历史数量；
- 是否使用会话摘要及摘要版本；
- 长期记忆是否启用、本次使用数量；
- 上下文 token 预算、占用比例及是否发生裁剪；
- 缓存命中和上下文构建耗时；
- 本轮是否保存记忆或生成新摘要。

打开“记忆设置”后，本次实际使用的记忆会显示“本次已使用”并高亮。自动保存
的偏好会明确标记为“自动保存”，不会与手动记忆混淆。

## 5. 证据边界

本轮修改完成后只运行本地静态检查和回归测试，没有再次发起付费真实模型
重测。因此：

- 72/100 是修改前刚完成批次的真实结果；
- 边界检索优化和端到端预算的具体超时改善，需要下一轮真实重测确认；
- 本地测试通过不能代替真实模型答案质量验收。
