# 知识库计划

## 首版范围

首批只上传 `knowledge_base/circuit_theory/`。文件按“课程总览、公式方法、题型、读图、错因、测试题”拆分，使检索片段主题单一、来源明确。

模电和数电仅用于验证未来扩展目录，不作为首版完整知识库。

## 整理规范

- 一个文件只承担一种信息类型；标题表达检索主题。
- 公式同时写变量、单位、方向约定和适用条件。
- 题型只给方法框架，不堆积重复例题。
- 不确定、待核验或超出课程范围的内容明确标记。
- 每次上传记录课程、文件、版本、日期和测试结果。

## 迭代顺序

1. 电阻电路与基本定律。
2. 等效变换、节点法、网孔法和电路定理。
3. 一阶动态电路。
4. 正弦稳态与功率。
5. 三相电路与互感电路。

扩展内容进入正式知识库前，至少经过教师审核和对应测试案例验证。
