# Dashboard 使用说明

## Admin `/admin`

进入“产品分析”后，先设置时间窗口，再按课程、角色、意图、能力、场景、Provider、模型、Pilot 批次或任务 ID筛选。分析页复用同一查询契约，标签页只改变聚合维度：总览、用户、会话、任务、回答质量、Agentic、性能、课程。

页面展示：

- 指标卡：活跃用户、DAU/WAU/MAU、会话、任务、完成/失败/回访、反馈、证据/引用、人工复核；
- 趋势表：按请求时区的每日用户、会话、消息、任务和完成任务；
- 分布：课程、意图、能力、技能、工具、场景、Pilot 批次、状态等；
- 定义与告警：每次报告附带指标口径、窗口、截断和时区回退提示。

`/debug/execution` 仍用于单任务 trace，不由 Dashboard 替代。Dashboard 默认不返回原始 Prompt、附件原文、密钥或学生身份明细。

## Teacher `/teacher`

教师登录后可按课程和窗口查看活跃学生、问题数、任务数、完成率、反馈覆盖率和需要复核数量，并继续使用原有反馈采纳、课程材料、OCR 和课程资产就绪度模块。Provider、模型和内部执行细节不下沉到教师页面。

## 权限与空数据

- Admin 分析接口要求 admin；未登录为 401，非管理员为 403。
- Teacher 分析接口要求 teacher 或 admin；学生不能读取课程聚合。
- 空窗口不显示 0% 的假精度，比例指标返回 `null`，UI 显示“—”。
- `row_limit` 可在 100–20,000 之间设置；超限结果必须按概览使用，并关注告警。
