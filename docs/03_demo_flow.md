# 演示流程

## 场景

学生围绕“含受控源的一阶 RC 电路”完成概念问答、题图解析、纠错和复习规划；教师查看匿名汇总结果。

## 演示链路

1. 询问“求时间常数时为什么不能把受控源置零？”
2. 上传一张 RC 电路题图，要求识别元件、连接关系和待求量。
3. 学生提交错误步骤，由 Agent 指出错因标签和修正方向。
4. 输入三次练习结果，生成三天复习计划。
5. 输入班级匿名统计，生成教师分析摘要。

## 演示要求

- 使用 `demo/demo_inputs.md` 的固定输入，保证可复现。
- 关键结果与 `demo/demo_outputs_sample.md` 对照，不要求逐字一致。
- 图片缺失或模糊时演示“请求补充信息”，不演示猜测答案。
- 全流程控制在 8 分钟内。
