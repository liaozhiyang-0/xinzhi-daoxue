# 统一 Web 导航指南

| 页面 | 路径 | 用途 |
|---|---|---|
| 统一首页 | `/` | 产品说明与主要入口 |
| 智能学习 | `/student` | 三课程问答与 CT 解题 |
| RAG 调试 | `/debug/rag` | 检索、Evidence、Cloud、引用与评测 |
| Agent 管理 | `/debug/agents` | 注册、契约、Dry Run 与 Mock |
| 系统状态 | `/system` | 轻量健康与配置摘要 |
| 演示中心 | `/demo` | 会议场景入口 |
| 旧演示入口 | `/debug` | 兼容旧书签，复用演示中心 |

所有页面共享左侧导航、顶部栏、主题与状态文案。移动端使用顶部“菜单”按钮打开抽屉。演示模式在任意支持的页面 URL 后增加 `?presentation=1`；从演示中心跳转时参数会自动传递。

不要在前端添加新的 Provider、RAG 或任务分支。新增页面应引用四个共享 CSS 和 `ui-core.js`，通过现有 API 获取数据，并在 `ui-core.js` 的导航数组中登记。
