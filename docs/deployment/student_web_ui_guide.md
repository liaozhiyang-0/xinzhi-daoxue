# 学生端 Web UI 指南

访问 `/workspace` 或 `/student`。知识问答支持 CT、AE、DE；专业解题支持文字题和最多8张有序图片。示例按钮只把问题填入输入框，不自动调用 API。

输入区支持 Enter 发送、Shift+Enter 换行、课程选择、多图批量选择或连续追加、逐图缩略图/删除和“高级选项”。任务流程保持为：创建会话、按显示顺序上传附件、一次 `POST /api/v1/tasks`、SSE 监听、读取最终任务。用户可停止任务、新建会话、复制回答、展开来源、继续追问或重新提问。

回答顶部显示可读路由，例如“知识问答 · 模拟电子技术”。教材来源默认折叠，只显示可读标题、课程、章节、内容类型和摘要。云端失败时明确显示本地知识库降级说明；Mock 结果明确标记为开发模拟。学生端不显示内部 Trace、原始向量、完整 Flow ID 或异常堆栈。

URL 可预填 `mode=learn|solve`、`course=CT|AE|DE`、`prompt=...`、`image=1` 和 `presentation=1`，预填不会自动发送。
