# 总体路由 Agent

## 目的

任务创建接口仍然只做快速、可复现的规则路由并立即入队。后台任务开始后，在外部检索、知识库检索和内容生成之前，调用一次快速模型，对原始用户输入和候选业务路径进行复核。模型只返回结构化路由，不生成答案。

## 现有业务路径

| 路径 | 适用任务 |
| --- | --- |
| `GENERAL_QUESTION_V1` | 无法可靠归类、跨领域或需要澄清的问题 |
| `LEARN_01_KNOWLEDGE_QA_V1` | 课程概念解释、知识总结、学习建议 |
| `ACADEMIC_PROBLEM_SOLVER` | 公式、数值、推导、电路题和图像题 |
| `TEACH_01_LESSON_PREP_V1` | 教案、课堂流程、形成性评价 |
| `TEACH_02_ASSIGNMENT_REVIEW_V1` | 作业初审、答案检查和反馈 |
| `RESEARCH_01_ACADEMIC_SEARCH_V1` | 查找、推荐、最新或相关论文/文献 |
| `RESEARCH_02_ACADEMIC_WRITING_V1` | 改写、润色、摘要化已有学术文本 |
| `RESEARCH_03_DATA_ANALYSIS_V1` | 数据分析、统计解释和可复现分析计划 |

论文检索和学术写作是两个独立路径。用户说“查找/推荐/最新论文”时应进入论文检索；用户说“改写/润色/写摘要”时才进入学术写作。

## 低延迟与降级

- 总路由使用 `qwen_text_fast`，默认最多生成 160 tokens。
- 总路由超时默认为 10 秒，并关闭模型路由级 fallback，避免一次路由变成多次模型调用。
- 模型不可用、超时、输出不符合协议或返回未注册 Agent 时，继续使用原有规则路由。
- 任务创建接口不等待总路由；路由耗时记录在 `route_latency_ms` 和 `structured_result.overall_routing` 中。
- 模型选出的目标必须经过本地 Agent 注册、输入类型和可用性校验，不能直接执行模型返回的任意字符串。
