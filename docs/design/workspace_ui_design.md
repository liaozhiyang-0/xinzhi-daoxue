# 智能任务工作台 UI 设计

## 信息结构

`/workspace` 是核心路径，`/student` 复用同一页面以保持兼容。

```text
AppShell
├── 左侧：产品导航、环境状态与主题
├── 中间：模式、会话、回答与固定输入区
└── 右侧：资料依据 / 执行过程 / 回答信息
```

右侧面板在宽屏默认打开；1180px 以下变为右侧抽屉；620px 以下变为底部抽屉。1280×720 演示模式收窄左栏并默认保留证据面板。关闭面板只改变本地界面状态，不重新请求后端。

## 视觉原则

- 以留白和稳定阅读宽度组织页面，回答正文不使用厚重气泡或卡片套卡片。
- 主色只用于主动作、当前导航与引用联动；状态色只表达状态。
- 普通卡片取消阴影，阴影只用于输入悬浮区、抽屉和 Dialog。
- 输入/按钮使用中等圆角；动画限制为 180–200ms，并尊重 `prefers-reduced-motion`。
- 深色主题使用同一层级关系，不使用发光或大面积渐变。

## 核心交互

输入区支持自动增高、Enter 发送、Shift+Enter 换行、图片缩略图、停止、重复提交保护和折叠高级选项。正文中的 `[S1]` 由安全文本渲染器生成按钮，点击后打开资料面板并高亮对应证据。图片只接受安全 `kb-image://` URI，使用缩略图、懒加载和放大 Dialog。

前端不解析 BM25、RRF、Point ID 或内部 Prompt。回答标题、来源摘要、Provider 文案、证据状态和 fallback 文案都来自后端 presentation 层。
