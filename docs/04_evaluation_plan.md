# 评测计划

## 评测维度

| 维度 | 判定标准 |
|---|---|
| 正确性 | 结论、公式、方向和单位无明显错误 |
| 完整性 | 包含适用条件、关键步骤和必要提醒 |
| 可追溯性 | 能指出使用的知识主题；不伪造来源 |
| 稳健性 | 信息不足时追问；图片模糊时标记不确定项 |
| 教学性 | 优先给方法和提示，不只给最终答案 |
| 隐私性 | 不推断或暴露学生身份，不输出个体排名 |

## 执行方法

1. 使用 `test_cases/` 中固定案例，温度等平台参数保持一致。
2. 每个案例记录日期、Prompt 版本、知识库版本、实际输出和 0/1 结果。
3. 关键事实错误、编造图中参数、越权使用个人数据均判为失败。
4. 修改 Prompt 或知识库后重新执行全部核心案例。

## 首版门槛

- 课程问答核心案例：100% 无关键事实错误。
- 图片解析：100% 列出不确定项，且不编造缺失连接或数值。
- 学习规划、教师报告：100% 仅使用给定数据。
- 全部案例综合通过率不低于 80%。

星辰平台实际结果需人工执行后填写；仓库不预置虚构通过记录。
