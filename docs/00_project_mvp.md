# 项目 MVP 定义

## 目标

在星辰 Agent 平台上搭建一个可演示的电子信息课程助手，证明电路理论知识问答、题图解析、个性化学习建议和教师侧汇总四类能力可以形成闭环。

## 首版交付

- 5 份智能体 Prompt；
- 以电路理论为核心的轻量知识库；
- 模电、数电扩展样例；
- 四类测试案例和一条演示流程；
- 明确的人工评测表。

## 不在范围内

- 独立 Web/App、后端 API、数据库和账号系统；
- 模型训练、微调、批量推理平台；
- 自动阅卷、正式教学决策或大规模课程内容生产；
- 真实学生隐私数据接入。

## 成功标准

1. Prompt 可直接复制到星辰平台并完成分流。
2. 电路理论问答能引用知识库，公式条件和单位说明完整。
3. 图片不清晰时主动指出不确定项，不编造拓扑或参数。
4. 规划和教师报告只基于提供的数据生成。
5. 核心测试通过率达到 `docs/04_evaluation_plan.md` 的门槛。
