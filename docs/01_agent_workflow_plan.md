# Agent 工作流计划

## 角色与输入

| Agent | 主要输入 | 主要输出 |
|---|---|---|
| 总控 Agent | 用户请求、图片、上下文 | 意图判断、任务分流或直接回复 |
| 课程问答 Agent | 电路理论问题、学生推导 | 概念、公式条件、步骤提示、错因 |
| 图片解析 Agent | 题目截图、电路图 | OCR、元件/连接关系、不确定项、求解建议 |
| 学习规划 Agent | 错因标签、测试表现、可用时间 | 分阶段复习计划和验收标准 |
| 教师分析 Agent | 去标识化汇总数据 | 薄弱点、证据、教学建议 |

## 分流顺序

1. 含图片或要求读图：图片解析 Agent。
2. 要求班级统计或教学建议：教师分析 Agent。
3. 要求复习计划：学习规划 Agent。
4. 其余课程概念、公式、解题与纠错：课程问答 Agent。

图片解析后若需要求解，将结构化识别结果连同原问题交给课程问答 Agent。信息不足时先追问，不得假设缺失参数。

## 星辰平台搭建顺序

1. 先分别创建四个专业 Agent 并配置知识库。
2. 用 `test_cases/` 单测每个 Agent。
3. 创建总控 Agent，配置上述分流规则。
4. 测试多轮上下文和跨 Agent 交接。
5. 固化通过版本的 Prompt、知识库批次和测试记录。
