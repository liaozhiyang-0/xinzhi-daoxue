# 竞赛材料包（工作骨架）

本目录用于整理项目提交材料，不代表已经完成竞赛申报，也不代表已经通过官方验收。

当前边界：

- 官方赛题 PDF、评分规则和授权信息尚未在本仓库完成核验；不得据此推导官方评分结论。
- 三个演示案例由项目负责人自行设计，本材料包不自动生成、不修改案例正文。
- 评测、Mock、离线校验和本地知识库结果必须与真实 Provider、真实用户结果分开标记。
- `SOLVER_CT v1.0`/`SOLVER_CT_V1` 是冻结基线，本材料包只引用其边界，不修改其实现。
