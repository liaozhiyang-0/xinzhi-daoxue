# MVP 演示脚本

## 准备

- 在星辰平台配置 5 个 Agent。
- 首批上传 `knowledge_base/circuit_theory/`。
- 打开 `demo_inputs.md` 和 `demo_outputs_sample.md`。

## 8 分钟流程

1. **课程问答（1 分钟）**：输入 D1，展示公式适用条件和受控源处理。
2. **图片解析（2 分钟）**：使用一张自备清晰 RC 题图并输入 D2；展示结构化识别。若无图片，使用 D2-F 演示拒绝猜测。
3. **纠错（1 分钟）**：输入 D3，展示错因标签和修正提示。
4. **学习规划（2 分钟）**：输入 D4，展示三天计划和复测标准。
5. **教师分析（2 分钟）**：输入 D5，展示基于匿名汇总的教学建议。

演示者只描述实际输出。若平台未命中预期，记录案例和版本，不临场补造结果。
