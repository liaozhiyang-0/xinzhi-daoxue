# 电路题图解析要点

## 必须识别

- 题干、已知量、单位和待求量；
- 元件类型、编号、数值、极性和参考方向；
- 节点、接地、交叉连接点、支路和端口；
- 开关在 `t<0` 与 `t=0` 后的状态；
- 受控源类型、控制量和增益；
- 互感同名端、变压器匝比和三相连接方式。

## 易混淆项

- 导线交叉不一定相连，以实心节点或图例为准。
- `1`、`l`、`I`，以及 `0`、`O` 容易被 OCR 混淆。
- `m`、`μ`、`k` 等倍率和电压/电流箭头不可省略。
- 模糊处必须列为不确定项；关键连接不清时停止求解。

## 推荐结构化记录

使用“题干、元件表、节点/支路表、参考方向、待求量、不确定项”六部分，便于后续课程问答 Agent 复核。
