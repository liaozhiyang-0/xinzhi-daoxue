# 电路理论典型题型

| 题型 | 首选方法 | 关键检查 |
|---|---|---|
| 多节点电阻网络 | 节点电压法 | 参考节点、超节点、受控关系 |
| 平面多回路网络 | 网孔电流法 | 共享支路符号、超网孔 |
| 端口等效与负载 | 戴维南/诺顿 | 端口定义、受控源保留 |
| 换路暂态 | 三要素法或微分方程 | 初值连续性、终值、时间常数 |
| 正弦稳态 | 相量法 | 有效值、相位、阻抗符号 |
| 交流功率 | 复功率 | 电流共轭、P/Q/S 单位 |
| 对称三相 | 单相等效 | 相序、Y/Δ、线量/相量 |
| 互感电路 | KVL/端口方程 | 同名端、互感项符号 |

答题时先识别题型，再说明为什么该方法适用；若题图或条件不足，不进入计算。
