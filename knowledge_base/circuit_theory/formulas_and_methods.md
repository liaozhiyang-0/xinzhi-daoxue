# 电路理论公式与方法

## 基本定律

- 欧姆定律：关联参考方向下 `u = Ri`；非关联方向时符号相反。
- KCL：任一节点电流代数和为零。
- KVL：任一闭合回路电压代数和为零。
- 吸收功率：关联参考方向下 `p = ui`。

## 常用分析方法

### 节点电压法

选择参考节点，对其余节点写 KCL。含理想电压源跨两个非参考节点时使用超节点，并补充电压约束。

### 网孔电流法

适用于平面电路。含公共理想电流源时使用超网孔，并补充电流约束。

### 戴维南/诺顿等效

端口开路电压为 `U_th`，等效电阻为从端口看入的 `R_th`。求 `R_th` 时独立电压源短路、独立电流源开路，受控源必须保留；必要时加测试源。

### 一阶动态电路

连续性：`u_C(0+) = u_C(0-)`，`i_L(0+) = i_L(0-)`。零状态或直流换路的一阶线性电路常写为：

`x(t) = x(∞) + [x(0+) - x(∞)] e^{-t/τ}`。

其中 RC 电路 `τ = R_eq C`，RL 电路 `τ = L / R_eq`；`R_eq` 从储能元件端口看入，受控源保留。

### 正弦稳态

阻抗：`Z_R=R`、`Z_L=jωL`、`Z_C=1/(jωC)`。复功率 `S = U I* = P + jQ`，电压电流使用同一有效值约定。

## 使用要求

每次套用公式前说明线性、稳态、对称、一阶或参考方向等前提；未满足前提时返回基本定律重新建模。
